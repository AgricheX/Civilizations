## English

### What it adds

- Hundreds of technologies across several development paths: real-world, steam, Tesla-inspired, diesel, atomic and biological.
- Customizable governments and ideologies, elections, xenophobia and xenophilia.
- Corporations, currencies and energy systems.
- Trains, airplanes and rockets.
- A spherical world and an internet for NPCs.

Also on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3824063532).

### How to install

1. Install NML for WorldBox (current version).
2. Download **Civilizations.zip** with the link above.
3. Extract it into the `Mods` folder of your WorldBox installation, so you get `Mods/Civilizations/mod.json`.
4. Start the game.

## Português (Brasil)

### O que o mod adiciona

- Centenas de tecnologias em vários caminhos de desenvolvimento: real, vapor, inspirado em Tesla, diesel, atômico e biológico.
- Governos e ideologias personalizáveis, eleições, xenofobia e xenofilia.
- Empresas, moedas e sistemas de energia.
- Trens, aviões e foguetes.
- Um mundo esférico e uma internet para os NPCs.

Também na [Oficina da Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3824063532).

### Como instalar

1. Instale o NML para o WorldBox (current version).
2. Baixe o **Civilizations.zip** pelo link acima.
3. Extraia na pasta `Mods` do WorldBox, de forma que fique `Mods/Civilizations/mod.json`.
4. Abra o jogo.
